# Tooltip-Regeln

1. Tooltip maximal 1–2 kurze Sätze.
2. Zuerst erklären **was** das Element tut, dann optional **warum**.
3. Keine Fachabkürzung ohne einfache Erklärung.
4. Keine sicherheits- oder fehlerkritische Information ausschließlich im Tooltip.
5. Tooltip-Texte müssen auch für Tastatur-/Screenreader-Nutzung eine Alternative besitzen.

Beispiel:

> **Backup erstellen** – Speichert eine zusätzliche Sicherung des aktuellen Datenstands. Empfohlen vor Importen oder größeren Änderungen.
